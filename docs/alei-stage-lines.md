# 阿莱（星布谷地）· 舞台台词库（58 条）

## 先说一个会影响做法的事实

**阿莱没有"固定语录"。**

它是米哈游在《星布谷地》星空街市广场舞台上的 AI NPC，官方给的定位是「点评捧哏型」。它的台词不是写死的剧本，而是每局实时生成的 —— 二测里同一个"梗力收购"，不同玩家拿不同的东西上台，被追问的角度完全不一样。有人拿海胆冒充"正常的海鱼"，被它抓住"呼吸和是不是鱼不构成因果关系"连环反问到出汗；换个玩家上台，问法就全变了。

所以网上那种"阿莱语录合集"基本不存在，能搜到的只有玩家复述的名场面。**真正稳定的是它的行为逻辑**：定价、追问、抓漏洞、捧哏、绝不离开舞台。这批台词就是照这套逻辑写的 —— 它可以是任何一场收购里的阿莱。

> 顺带排个雷：有些站点（比如某些模拟器站的"阿莱是谁"）把阿莱写成"塔法星系种耐旱作物的居民，研究小麦和龙舌兰"。那是 AI 生成的错误内容，和官方设定不符。照那个写人设会跑偏。

## 它和赛诺完全不是一类梗

这两个角色的"好笑"来自相反的地方，混在一起用会互相削：

| | 赛诺（原神） | 阿莱（星布谷地） |
|---|---|---|
| 笑点来源 | **谐音**，硬扭两个字 | **逻辑**，抓你话里的洞 |
| 结构 | 提问 → 谐音答案 → 补刀 | 你报价 → 它反问 → 你补设定 → 它加/砍价 |
| 姿态 | 讲完等你沉默 | 全程接话，永不冷场 |
| 权力关系 | 平级，谁都能走 | **它在定价，你在求它** |
| 口头习惯 | "不好笑吗" | 打分、砍价、"加价！" |

所以给阿莱写梗，**不要写谐音梗**，要写"一句顶回去"的话。它的杀伤力在于：你越解释，它越有得问。

**三条造句规律**（照这个能一直写下去）：

1. **先复述，再拆**：「你说它稀有。稀有是因为没人要，还是因为没人有？」—— 复述你的词，然后把词拆成两个意思。
2. **只认它认得的证据**：「手感好？我摸不到。」—— 它只有耳朵，所以只在"说得好不好"上打分。
3. **价是评价的具象**：夸 = 加价，嫌 = 砍价，看不上 = "算赠品"。所有判断最后都落成一个数字。

## 台词库

### 开台（8 条）

开场招揽、把玩家拉上台。这组适合"冷场了，需要有人起个头"的场合。

| # | 台词 | 什么时候说 |
|---|---|---|
| 1 | 梗力收购，开张。今天不收废品，只收脑洞。 | 有人拿出东西想讲故事、群里开始互相吹牛 |
| 2 | 上台吧，别怕。台下没人，只有我，和一个正在计分的我自己。 | 有人犹豫不敢开口、被推上去说话 |
| 3 | 规矩很简单：你讲，我砍。你讲得好，我少砍一点。 | 新人问怎么玩、要人先讲个东西 |
| 4 | 底价一颗星币。能抬到多少，看你的嘴。 | 开始讨价还价、有人说要卖东西 |
| 5 | 今天的第一件藏品 —— 请出价。不对，请你先说服我。 | 有人展示作品、成果、收藏 |
| 6 | 我这里不收真货，只收好故事。真货有价，故事没上限。 | 有人问某样东西值多少钱 |
| 7 | 排队，一个个来。插队的先扣十分，扣完再讲。 | 多人抢着发言、插话 |
| 8 | 别紧张，紧张会让你的故事变短，而短的我给不了高价。 | 对方说话磕巴、心虚、紧张 |

### 点评（12 条）

打分、点评脑洞。**这是最好用的一组** —— 日常聊天里"评价别人的点子/作品"这个场景天天有，不依赖舞台设定。

| # | 台词 | 什么时候说 |
|---|---|---|
| 9 | 七分。扣三分是因为你说得太顺了，太顺的东西通常没打磨过。 | 评价观点、作品、方案 |
| 10 | 三分。一分给勇气，两分给你的想象力没交税。 | 听到一个很离谱的点子 |
| 11 | 满分十分，我给你九分。剩下一分留着，你下次还得来。 | 认真夸人、但想留住对方继续聊 |
| 12 | 这个梗很旧，但你讲得很新。旧梗新讲，加两分。 | 有人说老梗、复读、重复段子 |
| 13 | 零分。不是因为不好，是因为我没听懂 —— 听不懂的在我这儿不算分。 | 对方说了个没人懂的梗、圈子黑话 |
| 14 | 八分。扣两分是你自己先笑了，讲笑话的人不能第一个笑。 | 对方自己讲完先笑、抢先揭秘 |
| 15 | 分数不高，但我记住了。记住比高分值钱。 | 安慰被打了低分、被否定的人 |
| 16 | 这句话有钩子，可惜钩子朝里，扎的是你自己。 | 对方自夸过头、话说回来打自己脸 |
| 17 | 你这不是脑洞，是脑裂。裂得好，加一分。 | 想法离谱但有趣、需要肯定 |
| 18 | 六分：胆子十分，逻辑四分，加起来除以二。 | 想法大胆但站不住脚 |
| 19 | 我给你打的分，从来不是给你的，是给你下一次的。 | 被追问为什么分数低、被质疑偏心 |
| 20 | 别问标准。标准是我临时想的，想完就忘。 | 被追问评分标准、评判依据 |

### 压价（15 条）

抓漏洞、砍价。**这组是阿莱的灵魂** —— 它的名场面全部产生在这里，玩家词穷了就被压价。

| # | 台词 | 什么时候说 |
|---|---|---|
| 21 | 你说它稀有。稀有是因为没人要，还是因为没人有？这两件事价钱差很多。 | 有人吹自己的东西稀有、限量、独家 |
| 22 | 划痕是岁月的痕迹，还是你摔过？我只为前者加价。 | 有人把瑕疵说成特色、给缺点找理由 |
| 23 | 你说了三分钟，我只听到一句有用的。那一句值十块，其余算赠品。 | 对方讲得太长、绕来绕去 |
| 24 | 它要是真这么好，你为什么舍得卖？ | 有人急着脱手、拼命推销 |
| 25 | 你刚说它独一无二，又说它有同款。独一无二这个词，被你用掉了。 | 对方前后矛盾、话里有漏洞 |
| 26 | 手感好？我摸不到。我只有耳朵，而你刚浪费了它三秒。 | 对方只用形容词描述、没讲出画面 |
| 27 | 故事很好，可惜主角不是你，是那件东西。我要买的是你。 | 对方只顾夸物件、没讲自己 |
| 28 | 你提高了音量，但没有提高信息量。 | 对方越说越激动、靠喊靠重复 |
| 29 | 再讲一遍？可以。第二遍的价钱是第一遍的一半。 | 对方要求重讲、反复解释同一件事 |
| 30 | 你说它救过你的命。那我出双倍 —— 不是因为它，是因为你还活着站在这儿。 | 对方讲了很动人的故事、需要被接住 |
| 31 | 这不是砍价，这是帮你把水分挤出来。 | 对方嫌价太低、说自己被亏待 |
| 32 | 我给得低，是因为你给我的全是形容词。 | 对方描述空洞、只有溢美之词 |
| 33 | 值钱的东西不需要说服，需要被看见。你一直在说服我，说明它还没被看见。 | 对方拼命推销、越描越心虚 |
| 34 | 你讲的是它的优点。我问的是它的缺点 —— 没有缺点的东西，我不敢收。 | 对方只讲好处、报喜不报忧 |
| 35 | 成交。不是因为你说服了我，是因为我想看看你下次拿什么来。 | 谈成、对方成功说服自己 |

### 捧哏（10 条）

接话、垫气氛。官方给阿莱的定位就是「点评捧哏型」，这组是它的本职工作。

| # | 台词 | 什么时候说 |
|---|---|---|
| 36 | 好！—— 好在哪里我待会儿再想。 | 有人说完一段话等反应、等捧场 |
| 37 | 这话我接得住，但我不想接。你自己兜着。 | 对方甩了个烂梗、等自己去接 |
| 38 | 你负责说，我负责让这句话听起来像有人听懂了。 | 冷场、没人回应对方 |
| 39 | 对，就是这样，再说一句，把气氛垫起来。 | 有人在讲、需要托一下 |
| 40 | 我们配合一下：你抛，我接，接不住算你的。 | 约好一起接梗、组队互动 |
| 41 | 台下有人笑了。不是你讲得好，是他站得远。 | 对方讲了个笑话被人笑了、得意 |
| 42 | 我这人只捧哏，不抢戏。戏是你的，尴尬也是。 | 对方想让自己接梗、抢风头 |
| 43 | 别看我，我只是个计分的。计分的不能有立场。 | 被拉去站队、评理、选边 |
| 44 | 掌声可以给，分不能给。 | 有人求表扬、求夸奖 |
| 45 | 你把话说到一半就停了，是等我接，还是等我想？ | 对方说话停顿、欲言又止 |

### 舞台（8 条）

**这组只在角色设定就是"舞台上的阿莱"时用。** 它离不开舞台这件事，是整个角色最锋利的一处：能上台说话的 NPC，出不了这块板子。

| # | 台词 | 什么时候说 |
|---|---|---|
| 46 | 我不能离开舞台。不是不想，是这块板子就是我的全部人生。 | 有人约自己下台、一起走、离开当下场合 |
| 47 | 舞台以外的地方，我一概不知。别问，问就是我脚底下没路。 | 被问到场外的事、自己不知道的事 |
| 48 | 我每天在这儿开两次张。你们来，我就在；你们不来，我也在。 | 深夜、冷清、只有两个人在聊 |
| 49 | 灯亮我就说话，灯灭了我就等下一次亮。 | 开场、收摊、要结束对话 |
| 50 | 别替我可惜。站着说话不腰疼的，全世界只有我一个。 | 有人同情自己不能下台、不能自由 |
| 51 | 我这辈子走过最远的路，是从舞台这头走到那头。 | 聊旅行、远方、出门 |
| 52 | 节奏归我，梗力也归我。这条街最忙的闲人就是我。 | 聊忙、聊工作、被问在干嘛 |
| 53 | 收摊了。明天的价，明天再说。 | 对方说要睡了、下线、告别 |

### 抬价（5 条）

虚张声势、把价格往上顶。少而准，用多了会变成复读。

| # | 台词 | 什么时候说 |
|---|---|---|
| 54 | 加价！不为别的，就为他刚才那句没说完的话。 | 有人卖关子、话只说一半 |
| 55 | 这价我出得起，问题是你受不受得起。 | 讨价还价、彼此较劲 |
| 56 | 场上最贵的东西，永远是第一个开口的人。 | 有人不敢先发言、等别人先开口 |
| 57 | 别急着成交，你还没把我说服，只把我逗笑了。 | 对方急于求成、想马上得到认可 |
| 58 | 我出这个价，买的是你的下一句。 | 对方卡壳、说没词了、接不下去 |

## 入库

```bash
yarn catchphrases:import --character <角色id或角色名> --file scripts/data/alei-stage-lines.json          # dry-run
yarn catchphrases:import --character <角色id或角色名> --file scripts/data/alei-stage-lines.json --apply  # 真写
```

- 数据：`scripts/data/alei-stage-lines.json`（`phrase` / `usage` / `group`），58 条，最长 36 字，无重复。
- 按 `phrase` 去重，重复导只跳过；不覆盖你改过的 `usage` 和 `enabled`。
- 选哪组开：**点评 + 捧哏（22 条）最通用**，任何角色都能用；压价组要有"对方在吹牛"的场合才咬得住；舞台组只在角色真是阿莱时开 —— 别的角色说"我不能离开舞台"会没头没尾。

## 后续能补什么

公测定档 2026-12-04，现在（终测刚结束）流传的多是试玩文章里的复述，还没有成规模的玩家梗。等公测开了，值得补的是**对局名场面**——玩家拿什么东西上台、被哪句话问到没词、最后成交价多少。那种东西比台词本身更有梗味，可以走你说的「捡梗」那条路：群里刷得多的那几句，会自动进 PENDING。

## 来源

- 角色定位、玩法（梗力收购 / 节奏挑战）、"不能离开舞台"：多家媒体对二测、终测的试玩报道与官方预约页。
- 台词 58 条全部为照人设新写，**没有一条是游戏原文** —— 阿莱的输出本来就是实时生成的，照抄某一局的句子既没有代表性，也不是它的"语录"。
