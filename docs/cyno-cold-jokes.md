# 赛诺式冷笑话 · 台词库（79 条）

给梗语录（`character_catchphrases`）用的一批台词。每条都带 `usage` —— 梗语录的模型是**看时机原样说出**，没有时机说明的台词它一辈子不会说。

- 数据文件：`scripts/data/cyno-cold-jokes.json`
- 导入脚本：`scripts/import-catchphrases.ts`（`yarn catchphrases:import`）

---

## 一、这批台词长什么样

赛诺的笑话是**三拍**结构，不是单句俏皮话：

```
提问（看似正经）→ 答案（硬谐音）→ 补刀（不好笑吗 / 你自己品）
```

- 第一拍负责骗人认真听，第二拍是全部笑点，第三拍负责把尴尬推上去。
- 台词写成一条消息说完，因为梗语录一次只说一句、说完就结束。
- 谐音**必须生硬**。越勉强越对——"大风机关"的全部威力来自它讲不通。

**收尾句单独抽出来当梗用**（这 12 条在库里是独立条目，也可以挂在任何一条笑话后面）：

> 你可以不笑，但你不能不冷。
> 笑点已经冻住了，等春天再笑吧。
> 我讲笑话从不失手，只会失温。
> 你可以说我不好笑，但不能说我不冷。
> 我不是在讲笑话，我在做天气预报：局部有霜。

**自造新梗的四步**（照这个来，一分钟一条）：

1. **挑字**：从角色的名字、称号、技能、经历里抠一个字。
2. **找同音**：拿这个字去撞日常词（提纳里 → 踢哪里 / 寻鳞官；夜兰 → 夜阑）。
3. **造因果**：给同音词编一个"合理"的解释理由，理由越牵强越好。
4. **收一刀**：加一句「不好笑吗？」或者干脆什么都不加，等对方沉默。

反推演示：`妮露` → `泥路` → 下雨就成泥路 → 「为什么妮露下雨天不出门？因为一淋雨就变成水泥路了。」

## 三、怎么入库

**方式一：脚本（一次全导，推荐）**

```bash
# 先 dry-run 看看会加哪些
yarn catchphrases:import --character <角色id或角色名>

# 没问题再真写
yarn catchphrases:import --character <角色id或角色名> --apply

# 只想先试试前 20 条
yarn catchphrases:import --character <角色id或角色名> --apply --limit 20
```

脚本按 `phrase` 去重：同一句导两次不会变成两条，重复执行只跳过。已在库里的台词**不会覆盖**你改过的 `usage` 和 `enabled`。

**方式二：页面手动加**：`/characters/{id}/settings/catchphrases`，一条一条粘。79 条手点会很累，脚本更合适。

**导完先别全开。** 提示词一次只装 15 条（`CATCHPHRASE_PROMPT_LIMIT`），挑选规则是"没用过的排最前 → 冷却中的垫底"，所以 79 条全开的效果是：头几天她连着冒新梗，之后靠 2 小时冷却轮转，一天能听见七八次不重样。想让"梗感"更稳定，建议只开 15–20 条（A 组全开 + B 组挑 8–10 条贴合当前场景的），其余留着不放。

## 四、一个容易踩的坑

梗语录的提示词只写**匹配时机**、不写频率（"偶尔说一句"会被模型当默认答案，结果一句不说 —— 表情包那条踩过同一个坑）。所以 `usage` 写得越具体，命中率越高：

- ❌ 「聊天的时候说」→ 模型不知道什么时候算对上了
- ✅ 「有人抱怨、求助、求人办事时」→ 对上就能立刻用

B 组里凡是 `usage` 写成「聊 XX 时」的，都是靠话题词命中，属于较松的一档；如果你发现某条一直不说，通常是 `usage` 太笼统，改成"对方刚说完 XX 这个词"这种具体信号就行。
