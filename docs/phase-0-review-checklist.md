# Phase 0 审查清单

Phase 0 结束前由开发者与 AI 一起审查本清单。标记为“待本地验证”的项目不能当作已通过。

## 产品/规则
- [ ] 默认记忆快照间隔为 8 天，可按角色配置 1–365 天。
- [ ] 快照周期不是原始消息保留期限。
- [ ] 周期边界使用左闭右开区间。
- [ ] 修改周期默认下一周期生效。
- [ ] 手动快照不改变自动计划。
- [ ] 重新生成新建版本，历史版本保留。
- [ ] 无活动周期可跳过模型调用但需要记录状态。
- [ ] 快照来源能够追溯到消息或其他来源引用。

## 数据模型
- [ ] 角色和平台连接通过独立绑定模型关联。
- [ ] 全局记忆、已关联用户私人记忆、未验证外部身份范围相互隔离。
- [ ] 外部消息、scope、任务和快照版本有唯一性约束。
- [ ] 同一逻辑快照不能产生重复版本号。
- [ ] 应用层和数据库迁移共同保证同一个 snapshotKey 只有一个 CURRENT 版本；如需要，使用 PostgreSQL 部分唯一索引 migration。
- [ ] 删除角色采用归档/明确的数据删除策略，避免误删来源与审计记录。

## API 契约
- [ ] 角色 API 字段与 Prisma model 一致。
- [ ] 会话和消息 API 足以写入原始事件。
- [ ] 记忆范围 API 能支持快照任务按 scope 执行。
- [ ] 快照 API 支持查看版本与排队重新生成。
- [ ] 所有写接口声明鉴权要求和错误响应。
- [ ] Mock 使用同一契约中的字段与枚举。

## 本地开发与数据迁移
- [ ] .env.example 无真实密钥。
- [ ] Docker PostgreSQL 仅绑定本机回环地址。
- [ ] backups 目录和 dump/sql 文件被 Git 忽略。
- [ ] PowerShell 备份/恢复脚本已在 Windows + Docker 环境测试。
- [ ] 恢复流程先针对空的测试数据库验证。
- [ ] 本地数据备份存放在仓库外的安全位置。

## 验证状态
- 代码与文档静态审查：进行中。
- Prisma CLI 验证：GitHub Actions 已在依赖安装环境中通过（以最新 run 为准）；仍建议开发者本地执行。
- OpenAPI lint：已加入 GitHub Actions，等待本次契约版本的检查结果。
- Windows 备份/恢复实测：需要在目标环境执行。

推荐命令（安装项目依赖后）：
```powershell
npx prisma format
npx prisma validate
```
