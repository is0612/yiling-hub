# 总览页 UI 改版 · 3 套设计稿

对 `app/pages/index.vue` 的三版视觉方案静态稿。全部**去掉了容器描边**，浅色主题，内容与当前线上页面一致（4 个角色、2 个异常、KPI 四格、事件流、最近任务、管理员块）。

直接用浏览器打开：

- `a-solid-blocks.html` — A 色块平铺
- `b-whitespace-editorial.html` — B 留白版面
- `c-soft-light-rails.html` — C 柔光轨道

`shots/` 里是 1440 视口的真实渲染图（无头 Chrome 截的，不是效果图）。

> 术语已跟随线上改动：「快照」→「归档」，导航「周期快照」→「阶段总结」，任务类型为「生成阶段总结 / 重新生成总结」。

## 三套一眼看差别

| | A 色块平铺 | B 留白版面 | C 柔光轨道 |
|---|---|---|---|
| 一句话 | 一张白台面，只有异常才上色 | 拆掉所有盒子，靠留白和一条发丝线立结构 | 用光代替线，每行左侧一条轨道说状态 |
| 靠什么分层 | 明度差（画布 → 白卡 → 浅灰砖） | 留白 + 字号 + 1px 语义分隔线 | 双层柔光 + 3px 轨道 |
| 有没有容器 | 有卡，零描边零阴影 | 无卡 | 有卡，柔光浮起 |
| 行怎么分 | 行间 4px 缝，hover 才成砖 | 1px 发丝线 | 无分隔，靠轨道 + hover 底色 |
| 异常怎么表达 | 红级整行浅底 + 行内竖条 + 实心药丸 | 行内左 3px 竖线 + 实心药丸 | 长轨 + 实心药丸 |
| 圆角 | 容器 10 / 行 8 | 只给控件（行与区块 0） | 容器 14 / 行 10 |
| 字号 | 12 / 14 / 22 / 26 | 12 / 14 / 22 / 26（无图标） | 12 / 14 / 16 / 22 / 26 |
| 信息密度 | 高 | 低 | 中 |
| 脾气 | 克制、后台感 | 高级、杂志感 | 友好、产品感 |

最明显的辨识点：**A 看 KPI 是四块没有边线的白砖；B 看页面根本没有卡片，只有通宽分隔线；C 看画布明显更深、每行左边有一截彩色轨道。**

## 三套共用的规则

**去描边的三条纪律**

1. 层次只允许落在明度、形状（竖条/轨道）、文字明度、阴影上，不允许用 1px 描边补层次。
2. 焦点态统一 `outline: 2px solid #d94a76`，三套都写了 `:focus-within` —— Tab 到行内链接时整行先亮起来。
3. 选中/异常用「左侧竖条 + 底色」表达，不用描边。

**异常必须有三个通道**（色弱和灰度打印下也成立）

- 文字：药丸里一定有字（模型未配置 / 归档逾期 / 任务失败 / 运行中 / 已暂停）
- 明度：异常药丸是**实心深底白字**，正常是软底深字 —— 灰度下「深块 = 要处理」
- 形状：行内竖条或轨道，且**只有要处理的行才有**（已暂停不画灰竖条，`#d5d9df` 对白卡只有 1.42:1，画了也看不见）

**其它**

- 字号只有 12 / 14 / 16 / 22 / 26，最小 12px
- 「开始对话」后面带角色名，原文案不说跟谁对话

## 本轮按 refactoring-ui 走查后的改动

用新装的 `refactoring-ui` skill 走了一遍七视角（层级 → 间距 → 排版 → 色彩 → 深度 → 图像 → 收尾），26 条 finding。已落地的：

| 改动 | 理由 |
|---|---|
| C 套事件流/任务流从「全是长轨」改成「短轨 + 异常行拉长」 | 角色区立了「长轨=要处理、短轨=正常」的规矩，右栏 8 行全是长轨，这个信号等于没有 |
| A 套加行间 4px 缝、行内 padding 14→12 | 静止态行没有分隔线，边界全靠 padding，5 行连排从第 3 行起就散了。净高不变 |
| 任务标题并入状态：`生成阶段总结 · 已成功` | 原来 4 行里 3 行标题完全一样，只能读 12px 的 meta 或看圆点颜色 |
| KPI 标签改 12/500 + `--text2` | 标签和脚注原来同为 12px 同色，扫四格时糊成一片 |
| 角色 facts 串从 `--dim` 提到 `--text2` | 一行里 facts / 周期文案 / 三个链接三组同色同号，层级平掉 |
| 统一「第 3/8 天」写法 | KPI 脚注写「第 3 / 8 天」、角色行写「第 3/8 天」，同屏相邻 |
| B 套「最近任务」上边距 28→44 | 组间和组内都用 1px 线，8 行连读像一条流的第 5 节 |
| A 套侧栏 hover 底色降一档 | 原来 hover 和选中同一个底，鼠标移到别项时两项长得一样 |
| 品牌方块字重 800→700 | 全站只有这一处 800 |
| 12px 图标补 `stroke-width:2` | 24 viewBox 缩到 12px，笔画只剩 0.8px，1x 屏发虚 |

**没改、留给你定的**：

- **KPI 前两格「距下次归档」和「最近一次归档」容易混**：都以「归档」结尾，值位一个是 `3 天` 一个是 `08-06`。建议改成「还有多久」和「上次归档」（四个标签开头字全不同）。这需要改线上文案，不只是视觉。
- **缺间距阶**：三份稿合计约 22 个不同间距值，A 套里「页头→异常条」16、「异常条→KPI」14、「KPI→区块」20，三个都是板块之间却写了三个数。项目有字号阶、圆角阶、阴影阶，唯独没有间距阶。建议立 `4/8/12/16/24/32/48` 七档。
- **C 套圆角有 7/9/10/12/14 五档**，项目契约只有 10/8/6 三档，落地时要收敛。
- **空态没画**：三份稿都只有满数据态。线上有首访引导、空事件、空任务、loading 四种状态，落地时这四处会保留旧样式。

## 落地时的约束

- **不要改 `app/assets/css/main.css` 里的 `.card` / `.kpi` / `.pill` / `.btn`** —— 那四个类被二十多个页面共用。用 `.page-wrap` 上的作用域类（`.ov-a` / `.ov-b` / `.ov-c`）在本页 `<style scoped>` 里覆盖。
- 进度条填充一律纯色，删掉现有的 `linear-gradient(90deg,#e86b92,var(--brand))`。
- 药丸永远不加 1px 描边。
- C 套的画布色 `#eef1f6` 要写在页面根节点上（`.page-wrap` 本身是透明的，只改 `--bg` 变量不会生效），并且补 `min-height: calc(100vh - 56px)`，否则内容不满一屏时底部会露出 body 的浅色，出现横向色差接缝。
- 三套共用同一套 class 名和 DOM，只有 `<style>` 不同 —— 转成 Vue 时改的是 CSS 不是模板，可以进一步做成一套 class + 三组 `data-skin` 变量。

## 已知行为

- 角色行实际高 **88px**（padding 12×2 + 名字行 22 + facts 18 + 进度行 18，A 套另加 4px 行间缝）。一屏可用高实算 422px（1440×900），5 行 = 440px，会差一点，需要滚动或把行再压 4px。这是落地决策，不影响设计稿观感。
- 三份稿只做了 1150px 的单列降级，没有做 720 / 640 的移动端布局 —— 那是落地时的事。
- 稿子里的交互（hover / focus）都是真的，鼠标划过去能看到行变成砖、按钮变色、链接出现下划线。

## 三处刻意的偏离（评审时别当成 bug）

1. **A 套的「归档逾期」那行没有整行浅底**，只有 4px 琥珀竖条 + 实心琥珀药丸。A 的整行浅底是全页唯一的分块信号，一屏里两行都铺色就会变成拼贴。只有「模型未配置 / 任务失败」这种红级异常才铺 `#fdecee`。
2. **A 套里只有异常行的元信息文字从 `#68717f` 提到 `#454f5e`**，其余行仍是 `#68717f`。因为 `#68717f` 落在 `#fdecee` 上只有 4.32:1，不达 AA。
3. **C 套「角色」区块的说明文案和另外两份不一样**，写的是「长轨待处理 · 短轨正常」。C 用轨道长短表达状态，不解释一句会被当成装饰。

## 选型建议

- 想**改动最小、风险最低**（只改 20 多行 CSS，和其他 20 多个页面共用一套语言）→ **A**
- 想要**最像"产品"而不是"后台"、且异常最容易被发现** → **C**（异常信号是轨道 + 实心药丸两个独立于底色的通道，不依赖那个只有 1.14:1 的浅粉底）
- **B** 的密度和结构改动最大（事件流时间要挪到左栏），不建议整体落地，但它的两个手法可以单独搬走：区块标题的「12px/700 + letter-spacing .12em」疏排、以及 2px 刻度式进度条。
